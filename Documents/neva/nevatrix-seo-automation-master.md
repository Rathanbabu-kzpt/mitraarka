## STEP 6B: INTERNAL LINKING STRATEGY

### Linking Rules
1. Every blog post links to its parent **Pillar Page**
2. Every blog post links to its relevant **Service Page** (1–2 contextual links)
3. Every blog post links to 2–3 **related cluster posts**
4. Service pages link back to related **blog posts**
5. Homepage links to all **5 Pillar Pages** in the blog section

### Anchor Text Best Practices
- Use keyword-rich anchors: "web development company in Warangal" → `/services/web-development`
- Vary anchor text: "our web development team", "website development services", "build your website"
- Never use generic anchors like "click here" or "read more"

## STEP 5: CONTINUOUS OPTIMIZATION LOOP

### Monthly SEO Audit Checklist
- [ ] Check Google Search Console for queries with impressions but low CTR → improve title/meta
- [ ] Identify posts ranking #4–#15 → strengthen with better internal links + content updates
- [ ] Check competitor blog for new posts → create counter-content within 2 weeks
- [ ] Update any blog post older than 6 months with fresh stats, examples, and keywords
- [ ] Monitor Core Web Vitals in Search Console → fix any LCP/CLS regressions
- [ ] Check for new "People Also Ask" boxes → add FAQ schema to matching pages

### Content Refresh Triggers
| Signal | Action |
|--------|--------|
| Ranking drops >3 positions | Refresh intro, add new H2, update statistics |
| Competitor publishes same topic | Add unique data, case studies, or deeper sections |
| Search intent shifts | Rewrite opening 200 words to match new intent |
| New product/service launches | Add internal links from old blog posts to new page |
| Google algorithm update | Audit E-E-A-T signals; add author bio, date, citations |
